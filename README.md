# BeefTV CanvasPro

[English](README.en.md)

BeefTV 的 CanvasPro 修改版 Windows 安装包与模型配置包。上游项目为 [glanderness/BeefTV](https://github.com/glanderness/BeefTV)，本仓库由独立维护者发布修改版，不代表上游官方发行。

[下载安装包与配置文件](https://github.com/Namm-star/BeefTV-CanvasPro/releases/latest)

## 安装与更新

1. 在 Release 中下载 `BeefTV-v2.2.5-windows-amd64-failure-classification-20261124-setup.exe`，保存画布、退出 BeefTV 后运行安装程序。
2. 在「模型配置」中填写自己的 CanvasPro API Key。
3. 老用户升级后，如仍显示旧配置包，在「模型配置 → 模型配置包」预览并应用内置更新，或导入本次 Release 附带的 JSON 文件。

支持 Windows x64。安装包未做代码签名。安装包与公开配置不包含用户 API Key、项目、数据库或代理设置；模型调用由所选 API 服务按其规则收费。

## 本版变化

- 按实际阶段区分未发送、提交结果未知、生成失败和结果取回失败。代理 TLS 握手及连接超时有未发送证据时可重试；已提交任务保留原任务保护。
- 图片、视频和音频下载失败统一提示继续取回，保留原任务号。下载权限、超时和中断不再误报为模型 Key 错误或用户取消；明确的鉴权、额度、审核、参数和本地存储原因继续保留。
- 排查信息显示直连或代理以及 DNS、TLS、等待响应等实际连接阶段，并区分原任务查询和结果下载。
- 修复异步图片生成完成后，制品下载失败被误报为“模型服务不可用”的问题。保留原任务号，使用原任务冻结的协议继续查询和取回；下载恢复不再次提交生成。
- 补齐配置包异步图片的恢复路径，并允许有原任务编号及有效查询协议的历史“无法取回”结论重新查询。原任务明确失败时结束恢复，返回任务号不一致时停止取回。
- 修复多张参考素材准备时提前报“缺少有效 HTTPS 地址”的问题：等待整组完成后再取得链接并提交生成，保留参考素材顺序。
- 移除上游 BeefTV 登录、余额、充值、官方账户连接与自动恢复入口。侧栏提供工作台设置和本修改版发布页，旧登录及充值接口不可用。
- 关闭上游应用自动更新，后续版本从本仓库 Release 下载，避免安装回带有上游账户模块的官方版本。
- 基于 BeefTV v2.2.5，保留 CanvasPro 原生模型配置、协议适配、结果下载代理和 ComfyUI 接入修正。
- 内置执行引擎 3 和 393 款模型配置：文字 33 款、图片 59 款、视频 301 款。
- 为已适配的即梦系列增加临时参考素材上传，支持批次创建、上传、状态查询及恢复；本地参考素材无需另配图床。
- 现有导入配置保持有效，可手动应用内置更新；运行中的任务继续使用原有协议快照。
- 提供模型配置维护 Skill，后续可按最新 API 文档生成可导入的 JSON 配置包。

发行构建对应修改提交 `dd6e667`。模型配置包版本为 `20261123-suanli-v1-pack1`；已使用该配置包的用户无需重新导入。升级会保留 CanvasPro 和其他自带 Key 的服务连接；原先使用上游官方账户的节点需要改选自带 Key 的模型服务。

出现取回错误时，优先对原任务点击「继续取回」，不要直接重新生成。此修复需要更新程序，单独导入模型配置包不会更新取回逻辑。

## 文件校验

Release 附带 `SHA256SUMS.txt`。在 PowerShell 中使用 `Get-FileHash -Algorithm SHA256 <文件路径>`，与文件中的校验值比较。
